# No More Room in Hell 2 — Toolkit

Fan-made player reference for **No More Room in Hell 2** (Steam appid 292000),
built **directly from the local game files** — same approach as the Icarus Toolkit.

Live site: deployed via GitHub Pages (see the repo's Pages URL).

The game runs on **Unreal Engine 5.6** (Torn Banner's custom "Mangle.4" build).
The paks are *unencrypted* and mount cleanly, but their asset contents use UE5
**unversioned properties**, so decoding the actual numbers (damage, health, magazine
sizes, zombie stats…) requires a **`.usmap` mappings file**.

## How we get the numbers without touching the anti-cheat

The game ships **kernel-level Easy Anti-Cheat** and hosts all multiplayer on the
developer's own cloud servers, so the usual way to make a usmap — injecting UE4SS /
Dumper-7 into the **running** game — is an account/ToS risk we don't take. There is
no offline dedicated-server build to target either.

Instead we use a **usmap borrowed from another UE 5.6 game** (a plain file download —
no injection, no EAC contact). A foreign usmap can't describe this game's *custom
Blueprint* types, but it fully describes the shared engine types — and it turns out
the entire **weapon / melee / throwable / zombie / item stat backbone lives in native
`UCurveTable` assets**, which decode perfectly. So we get real, from-files numbers for
those. **Skill** magnitudes live in Blueprint `GameplayEffect` objects that a foreign
usmap can't decode, so skills stay name-only (or wiki-sourced) for now.

## What's here

```
data/
  catalog/catalog.json     Names + asset paths of everything. Always works.
  stats/stats.json         Real numbers parsed from the game's curve tables.
  mappings/Mappings.usmap   Foreign UE5.6.1 usmap (git-ignored; download separately)
  stats-raw/               Raw CUE4Parse JSON dumps (git-ignored; regenerated locally)
site/                      Static site (self-contained; data.js is inline)
  data.js                  Site data (regenerated by tools/build_site_data.py)
tools/
  extractor/               .NET/CUE4Parse app: mounts paks, exports assets to JSON
  build_catalog.ps1        Rebuild catalog.json from the mounted file list
  build_stats.py           Parse stats-raw curve tables -> data/stats/stats.json
  build_site_data.py       Merge catalog + stats -> site/data.js
```

## Pipeline

### 1. Catalog — the names of everything
```
tools/extractor > dotnet run -- list GAME_UE5_6      # dumps file_list.txt (76,637 files)
powershell tools/build_catalog.ps1                    # -> data/catalog/catalog.json
```

### 2. Get a usmap (one download, ToS-safe)
Grab a **UE 5.6.x** `.usmap` from any other UE 5.6 game's modding community (e.g.
FModel mapping releases on Nexus) and drop it at `data/mappings/Mappings.usmap`.
Verify it's a real usmap: it starts with the bytes `C4 30`.

### 3. Extract the curve-table stats
```
tools/extractor > dotnet run -- export ../../data/stats-raw CT_ItemAttributes GAME_UE5_6 ../../data/mappings/Mappings.usmap
tools/extractor > dotnet run -- export ../../data/stats-raw CT_ATT_Zomb       GAME_UE5_6 ../../data/mappings/Mappings.usmap
python tools/build_stats.py                            # -> data/stats/stats.json
python tools/build_site_data.py                        # -> site/data.js
```

### 4. Preview
```
cd site && python -m http.server 8791    # then open http://localhost:8791
```

## What decodes (and what doesn't)

| Category | Count | Stats | Source |
|---|---|---|---|
| Firearms | 33 | 16 with full stat sheets | `CT_ItemAttributes_*` curve tables |
| Melee | 18 | all 18 | `CT_ItemAttributes_*` (+ rarity from BP tiers) |
| Throwables | 7 | 3 | `CT_ItemAttributes_*` |
| Zombies | 10 profiles | all 10 | `CT_ATT_Zomb_*` (base + **Prime** elite variants) |
| Responders | 75 backgrounds + 6 voices | roster only | `DT_CharacterBackgrounds` name map + `VS_*` voice sets (row props are game-native, undecodable) |
| Items | — | Battery, Medical | `CT_ItemAttributes_*` |
| Skills | 66 | name only | Blueprint GameplayEffects — need a native usmap |
| Consumables / Gear / Attachments / Recipes / Challenges | 19 / 19 / 19 / 39 / 17 | name only | catalog |

Firearms/throwables without stat tables are unreleased/cut content that has no
dedicated tuning in the shipped build.
